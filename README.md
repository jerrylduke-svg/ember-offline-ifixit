# iFixit offline reference collection for Ember

Source: [iFixit](https://www.ifixit.com/), archived by openZIM/Kiwix as `ifixit_en_all_2025-12.zim` (archive metadata date 2025-12-21). The archive contains community repair material, not a guarantee of current or safe instructions. This is a noncommercial offline reading/search adaptation, not an official iFixit product or endorsement.

## What changed

The source archive was reorganized into 42 compact searchable packages and one shared asset/model transport. Original resources were retained, deduplicated by content identity and indexed. Separate reading-copy HTML adds source/license/change notices and adapts navigation for offline reading. Selected credit links are preserved separately without inventing canonical web URLs. See CHANGES.md and ATTRIBUTION.md. The embedding model is a separate Apache 2.0 component; its exact LICENSE and NOTICE accompany this collection. Computing retrieval embeddings is not training that model.

## Integrity and scope

`corpus-artifacts.json` identifies the exact 43 logical ZIP transports; `credit-references.json` identifies 42 credit shards. SHA-256 hashes bind the bytes. If a hosting service requires segmented transport, the published segment descriptor must reconstruct the exact listed ZIP hash and size, not a repacked substitute. Do not assume an individually downloaded segment is an installable ZIP.

This release's source files and manifests do not establish Android device compatibility, complete Ember readiness, complete other libraries, or completeness of every upstream page. Known source placeholders and unavailable entries remain source limitations. No user chats, household profiles, credentials or private notes belong in this publication.
